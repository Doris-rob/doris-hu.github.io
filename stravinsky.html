CORE MECHANISMS

FIVE
RULES

节奏优先、块状结构、重复与变体、去个人化、历史重构——作品更换外观，机制保持连续。

节奏优先

重音错位，让身体先于旋律被卷入。

块状结构

A / B / C 模块突然拼接、突变和撞击。

重复变体

重复中改变长度、配器、音高或重音。

去个人化

人物后退，让仪式与秩序浮到前景。

历史重构

从民歌、巴洛克到十二音：不是复古，而是重新设计过去。

SENSORY WEATHER / MECHANISM LAYER

斯特拉文斯基

冷 · 锐利 · 颗粒
原始 · 跳跃 · 机械

像一个不断改变重心的仪式空间：力量不是流动，而是一次次精确的碰撞。

01不规则重音 + ostinato + 块状拼接
02强拍预期被打断，模块彼此撞击
03身体化、紧张、冷峻且不稳定

复节奏 → 重心不断移动 → 身体无法预测强拍 → 产生原始冲击感。

RUSSIAN
CROSS-SECTION

灵魂，还是语法？

拉赫玛尼诺夫保存俄罗斯的“灵魂”；斯特拉文斯基保存俄罗斯的“语法”。多数人仍在问音乐应当表达什么，他开始问音乐本身可以怎样被组织。
